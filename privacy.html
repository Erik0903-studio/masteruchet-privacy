Политика конфиденциальности Мастер⚙Учет

Дата редакции: 24 октября 2026 г.

Настоящая политика описывает обработку данных при использовании приложения «Мастер⚙Учет» для учёта ремонтов, клиентов, задач и складских записей.

Кто отвечает за обработку

Разработчик и контакт по вопросам данных: Erik0903, Россия. Email: masteruchet@gmail.com.

Какие данные обрабатываются

  • Данные аккаунта: адрес электронной почты, идентификатор аккаунта и токены сессии.
  • Профиль мастера: имя и телефон, если пользователь их указал.
  • Данные, которые пользователь вносит в приложение: имя и контакты клиента, адрес, тип и модель техники, описание неисправности и работ, даты, статус и стоимость ремонта, складские записи, задачи и время напоминаний.
  • Фотографии ремонта, если пользователь сам добавил фото «до» или «после».
  • Технические данные, необходимые для входа, синхронизации и защиты сервиса, которые обрабатываются Supabase как поставщиком облачной инфраструктуры.

Приложение не запрашивает разрешение на получение координат устройства и не использует рекламные или аналитические SDK. Адрес клиента — текст, который вводит пользователь; это не координаты, полученные с устройства.

Для чего используются данные

Данные нужны для входа в аккаунт, ведения карточек ремонтов и клиентов, учёта склада, создания задач и локальных напоминаний, отображения отчётов, синхронизации между устройствами, резервного локального хранения при отсутствии интернета и удаления аккаунта по запросу.

Где хранятся и кому передаются данные

Приложение хранит рабочие записи и профиль локально на устройстве, чтобы поддерживать работу без интернета. При входе и включённой облачной синхронизации данные передаются через HTTPS в проект Supabase, где работают Auth, база данных, Storage и серверная функция удаления. Supabase обрабатывает данные как поставщик инфраструктуры. Основные данные проекта (база, Auth и Storage) размещены в регионе AWS eu-west-1 (Ирландия). Supabase также указывает, что отдельная служебная обработка, поддержка и доставка файлов через CDN могут выполняться за пределами выбранного региона.

Если пользователь нажимает действие звонка, мессенджера или навигации, приложение может открыть соответствующую внешнюю программу с выбранным телефоном или адресом. Дальнейшая обработка этих данных регулируется политикой выбранной программы.

Пароль вводится для аутентификации через Supabase Auth; приложение не записывает сам пароль в свои карточки. Для сохранения входа приложение хранит токены сессии в локальном хранилище устройства.

Срок хранения и удаление

Рабочие записи хранятся, пока аккаунт активен или пока пользователь сам не удалит соответствующие записи. Пользователь может удалить аккаунт в настройках приложения. При подтверждённом удалении серверная функция удаляет аккаунт Supabase, строки аккаунта из таблиц ремонтов, склада, задач и профиля, а также его фотографии из Storage. Технические резервные копии и журналы инфраструктурного провайдера могут иметь отдельные сроки хранения в соответствии с настройками проекта и условиями Supabase.

Для запроса удаления без установленного приложения используйте страницу удаления аккаунта или напишите на email поддержки с адреса, связанного с аккаунтом. При удалении через веб-страницу локальная копия на устройстве удалённо недоступна и может быть удалена в самом приложении или очисткой его данных.

Защита и контроль

Соединение с облаком использует HTTPS, а вход выполняет Supabase Auth. Не добавляйте в записи данные, которые не нужны для ремонта. Пользователь отвечает за наличие законного основания для внесения персональных данных клиентов. Чтобы запросить доступ к данным, исправление, удаление или задать вопрос об обработке, напишите разработчику на masteruchet@gmail.com.
